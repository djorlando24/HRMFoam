# Flashing heated water spray nozzle - test case

Ankit's d=0.6mm nozzle with a cylindrical outlet plenum, with refinement inside the hole.

Set h = 0.110000E+07 and p = 60 bar inlet stagn pressure to obtain 526K (253C) compressed liquid at 0.796673E+03 kg/m3
Set back pressure 1 bar, ramping down over 10 ms for stability of initial condition.

Turned on Sigma-Y and k-epsilon turbulence model using laminar solution from t=10ms as starting point.
Estimate viscosity and surface tension at about 250C value, quite low.
